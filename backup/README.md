# Live Site Backup - krfitnessstudio.com

This folder contains a backup of the live website content before deploying the new Next.js version.

## Backup Date
November 30, 2024

## Backup Contents

### 1. Main Pages Backup (`live-site-main-pages/`)
Contains the main HTML pages:
- `index.html` - Homepage
- `about-us.html` - About Us page
- `services.html` - Services page
- `transformation.html` - Transformation page
- `contact.html` - Contact page
- `BACKUP_INFO.txt` - Backup information

### 2. Full Site Backup (`live-site/`)
Contains a more comprehensive backup including:
- All HTML pages
- CSS files
- JavaScript files
- Images and assets
- WordPress theme files
- Plugin files

## Source Website
https://krfitnessstudio.com/

## Purpose
This backup was created before deploying the new Next.js-based website to ensure we have a reference of the original WordPress site content and structure.

## Notes
- The main pages backup is a simplified version focusing on content
- The full site backup includes all assets but may be incomplete for dynamic content
- WordPress-specific files (themes, plugins) are included for reference
- This backup serves as a reference point and may not be fully functional as a standalone site

## Restoration
If needed, these files can be used to:
1. Reference original content structure
2. Extract text content
3. Compare with new site
4. Restore specific content if needed
